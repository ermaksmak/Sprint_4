# BooksCollector

## Описание проекта

`BooksCollector` — это класс для управления коллекцией книг. Класс позволяет добавлять книги, устанавливать для них жанры, фильтровать книги по жанрам или возрастной категории, а также работать с системой избранного. 

Кроме того, проект включает покрытие `unit-тестами` всех методов класса, чтобы гарантировать их корректную работу.

---

## Описание класса BooksCollector

### Атрибуты:
- `books_genre` — словарь, где в качестве ключей выступают названия книг, а значения — их жанры.
- `favorites` — список, содержащий избранные книги.
- `genre` — список доступных жанров книг: `['Фантастика', 'Ужасы', 'Детективы', 'Мультфильмы', 'Комедии']`.
- `genre_age_rating` — список жанров с возрастными ограничениями: `['Ужасы', 'Детективы']`.

---

### Методы класса BooksCollector:

#### 1. **add_new_book(name)**  
Добавляет новую книгу в коллекцию.  
- **Условия:**
  - Название книги не может превышать 40 символов.
  - Если книга уже существует в коллекции, она не будет добавлена.  

#### 2. **set_book_genre(name, genre)**  
Устанавливает жанр для книги.
- **Условия:**
  - Книга должна быть в коллекции.
  - Жанр книги должен быть из списка доступных жанров `genre`.

#### 3. **get_book_genre(name)**  
Возвращает жанр конкретной книги.
- Если книга отсутствует в коллекции, возвращает `None`.

#### 4. **get_books_with_specific_genre(genre)**  
Возвращает список книг с указанным жанром.
- **Условия:** Жанр должен быть из списка поддерживаемых.

#### 5. **get_books_genre()**  
Возвращает текущий словарь всех книг с их жанрами.

#### 6. **get_books_for_children()**  
Возвращает список книг, подходящих для детей.  
- **Условия:** У жанра книги не должно быть возрастного ограничения (например, жанры из списка `genre_age_rating` не вернутся в этот список).

#### 7. **add_book_in_favorites(name)**  
Добавляет книгу в список избранных.
- **Условия:**
  - Книга должна существовать в коллекции.
  - Нельзя добавить одну и ту же книгу в избранное дважды.

#### 8. **delete_book_from_favorites(name)**  
Удаляет книгу из списка избранных, если она там присутствует.

#### 9. **get_list_of_favorites_books()**  
Возвращает список текущих книг в избранном.

## Описание тестов

Тесты выполнены на `unittest` и покрывают функции класса `BooksCollector`.  

### Тестируемые методы:

1. **test_add_new_book_add_books**
   Проверяет, что новая книга добавляется в коллекцию с пустым жанром по умолчанию.

2. **test_add_new_book_invalid_length_more_40**
   Проверяет, что книга с названием более 40 символов не добавляется в коллекцию.

3. **test_add_new_book_invalid_length_is_0**
   Проверяет, что книга с названием длиной 0 символов не добавляется в коллекцию.

4. **test_get_list_of_favorites_books_have_books**
   Проверяет, что книги, добавленные в избранное, корректно отображаются в списке избранных.

5. **test_set_book_genre**
   Проверяет процесс установки жанра и возврат жанра книги.

6. **test_set_book_genre_invalid**
   Проверяет, что установка недопустимого жанра для книги не меняет её жанр.

7. **test_get_books_with_specific_genre**
   Проверяет, что метод возвращает книги, соответствующие заданному жанру.

8. **test_get_books_for_children_list_is_empty**
   Убеждает, что список книг для детей пуст, если жанры всех книг имеют возрастное ограничение.

9. **test_get_books_for_children_list_is_not_empty**
   Проверяет, что книги с детскими жанрами корректно возвращаются.

10. **test_add_book_in_favorites**
    Проверяет добавление книги в список избранного.

11. **test_delete_book_from_favorites**
    Проверяет удаление книги из списка избранного.

12. **test_add_favorites_nonexistent_book**
    Проверяет, что несуществующую книгу невозможно добавить в избранное.

13. **test_add_duplicate_book_in_favorites**
    Проверяет, что книга не добавляется в избранное несколько раз подряд.

14. **test_set_and_get_genre**
    Проверяет корректность установки и получения жанра книги.

15. **test_adding_book_genre**
    Проверяет, что новая книга изначально добавляется с пустым значением жанра.

16. **test_books_with_no_genre**
    Проверяет корректное возвращение списка книг без указанного жанра.

17. **test_invalid_genre**
    Проверяет, что книги с неподдерживаемым жанром не находятся.

18. **test_get_books_genre**
    Проверяет корректное возвращение словаря всех книг с жанрами.

19. **test_get_books_for_children_no_books**
    Убеждается, что если подходящих книг нет, метод возвращает пустой список.
